# Gym Dub — En construcción

Landing page temporal para `gymdubmx.com`, diseñada para publicarse como un proyecto independiente en Cloudflare.

## Despliegue en Cloudflare

1. Sube el contenido de esta carpeta a un repositorio nuevo de GitHub.
2. En Cloudflare, crea un nuevo proyecto de Workers & Pages conectado al repositorio.
3. No se requiere comando de compilación.
4. Usa `/` como directorio raíz y de salida.

El dominio debe conectarse únicamente después de comprobar la URL temporal de Cloudflare.
